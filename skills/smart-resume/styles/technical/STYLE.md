# Technical Ledger · 技术工程 · 技術工程

## Identity
Section labels occupy a narrow left column, with supporting evidence to the right.
A vertical divider creates a technical ledger rather than decorative skill meters.
Suitable for engineering, software and data roles.

## Invariants
A4, 18 mm margins, a 32 mm label column and 6 mm gutter. Body remains 10.5 pt
with 16 pt leading; headings 13 pt, name 24 pt. Dark green accent on white.
Each section finishes below both columns before the next begins. Source order
is heading then claims; never rearrange facts solely to fill a column.

## Variation
Validated accent and regular/airy spacing. On a narrow HTML viewport the two
columns stack; PDF dimensions remain fixed. Photo is optional.

## Engine and acceptance
`scripts/resume.py`, layout `ledger`; `assets/resume.html`, style `technical`.
Inspect long wrapped labels, vertical dividers, paragraph wrapping and overflow.
Extract all selected text; no employer-specific ATS guarantee.
