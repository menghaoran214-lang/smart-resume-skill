# Changelog

## 0.2.0 - 2026-11-02

### Changed

- Moved the skill into `skills/smart-resume/`, matching the common Agent Skills layout.
- READMEs are now generated from `templates/` and `data/project.yaml` with an
  automatic table of contents, centered banner, badge row and a clickable
  directory tree.
- The first screen now answers what the skill is, who it is for and how to
  install it before any deeper detail.
- Added a scheduled workflow that refreshes the repository stats image and
  regenerates the READMEs.

## 0.1.0 — 2026-11-02

- Initial installable skill with Simplified Chinese, Traditional Chinese and English README navigation.
- Authorized-material intake, JD screenshot workflow and one exact target role.
- Source eligibility checks, explicit fictional demo mode and private review records.
- Two-page A4 PDF, editable HTML, overflow refusal and local font coverage checks.
- Non-overwriting installation, allowlisted ZIP packaging and behavioral tests.
